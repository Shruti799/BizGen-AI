🚀 BizGen-AI

BizGen-AI is an AI-powered business discovery platform that generates innovative business descriptions using the Google Gemini API.
Built with a modern full-stack architecture, it simplifies ideation and reduces content creation time significantly.

✨ Features
🤖 AI-generated business descriptions
🔐 Secure authentication with Clerk
⚡ Fast and responsive UI with Next.js & Shadcn
📊 Scalable backend with MongoDB
🌐 Deployed on Vercel with active usage monitoring

🛠️ Tech Stack
Frontend: Next.js, TypeScript, Shadcn UI
Backend: Next.js API Routes
Database: MongoDB
Authentication: Clerk
AI Integration: Google Gemini API
Deployment: Vercel
